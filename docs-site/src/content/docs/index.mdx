## What you get

One platform an agent provisions and operates on its own: a real **Postgres**
database with REST and row-level security, **user auth**, content-addressed
**storage**, Node **functions** and routes, **email**, and **Astro SSR** — all
shipped through one atomic deploy. You set a finite, prepaid **allowance**; the
agent builds and spends within it, and can't go past it.
