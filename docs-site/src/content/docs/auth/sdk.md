title: Application auth helpers
description: Stable compatibility destination for released documentation links.
---

Use the current `auth` namespace from `@run402/functions` inside the supported request context. `auth.user()` reads the actor; `auth.requireUser()` enforces authentication. Presentation components do not replace server authorization. See [application auth](/build/auth/) and the [native integration reference](https://github.com/kychee-com/run402/tree/main/astro).
