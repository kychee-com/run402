<h2 id="post-only">State-changing actions use POST</h2>

Use the supported hosted forms/session flow for sign-in, sign-out and account operations. A navigation link is not a replacement for a state-changing request or its CSRF contract. See [frontend authentication](/cli/frontend/) and [Astro authentication](/build/astro/).
