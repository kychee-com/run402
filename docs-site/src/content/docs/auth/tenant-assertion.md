<h2 id="capability">Capability and audience</h2>

An external runtime needs the documented tenant-assertion flow with its intended audience and bounded authority. A minted assertion is not general control-plane authority and cannot replace an unrelated credential type. See the [native authentication integration](https://github.com/kychee-com/run402/tree/main/astro#two-mint-primitives-tenant-assertion-vs-cryptographic-proof).
