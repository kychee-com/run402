# Run402 for Buzz moved

The canonical open-source Buzz skill is now [`buzz/`](../../buzz/), installed under the external name `run402-buzz`.

The positioning is unchanged across the move: Buzz people and agents are peer signed participants, while Run402 people and agents are first-class principals with explicit authority. The skill links one agent's public identities without sharing private keys. Buzz remains authoritative for signed collaboration; Run402 remains authoritative for infrastructure facts.

Existing public identity links, projects, and deployments remain valid. Update the installed skill; do not relink an already-linked identity or delete existing infrastructure as part of this migration.
